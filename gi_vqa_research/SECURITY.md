# Security Policy

Do not commit or report credentials, signed URLs, private dataset content, or
patient-identifiable information in a public issue.

Before a public remote is configured, report concerns privately to the
repository owner. After publication, use the hosting platform's private
security-advisory mechanism. Revoke exposed credentials immediately and scan
the complete Git history; deleting a value in a later commit is insufficient.

Only the current supported `main` branch receives security fixes.
