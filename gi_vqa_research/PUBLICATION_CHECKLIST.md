# Publication Checklist

- [ ] The repository has a reviewed public remote and project URLs.
- [ ] The full Git history passes secret scanning.
- [ ] `make publication-check`, tests, critical-error Ruff checks and package build pass on Python 3.11.
- [ ] No dataset, image, model weight, adapter or generated run artifact is tracked.
- [ ] Notebooks contain no outputs, execution counts or private paths.
- [ ] Protocol and implementation hashes validate.
- [ ] Official-test access remains accurately disclosed.
- [ ] Data/model licences and access instructions have been reviewed.
- [ ] Claims in the README match completed evidence.
- [ ] A release tag, archived release and associated-paper citation are added.
